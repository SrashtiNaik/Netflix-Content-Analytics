# 🎬 Netflix Content Analytics Dashboard using Python & Power BI

> 📊 An interactive data analytics project built using Python and Power BI to uncover insights from Netflix's Movies and TV Shows dataset.

---

## 📌 Project Overview

This project analyses the Netflix Movies and TV Shows dataset from Kaggle. The data was cleaned using Python (Pandas) and visualised in Power BI to identify trends in content, genres, ratings, countries, and more.

---

## 🛠️ Tools & Technologies

✅ Python  
✅ Pandas  
✅ Power BI  
✅ Microsoft Excel  
✅ Kaggle Dataset

---

## 📂 Dataset

📁 **Source:** Netflix Movies and TV Shows Dataset (Kaggle)

---

## 🔄 Project Workflow

📥 Collected the dataset from Kaggle

🧹 Cleaned and preprocessed the data using Python (Pandas)

📊 Imported the cleaned data into Power BI

📈 Created interactive dashboards and visualisations

💡 Analysed the data to generate meaningful business insights

---

## 📊 Dashboard Features

🎯 Total Movies & TV Shows

🌍 Country-wise Content Analysis

🎭 Top Genres

⭐ Ratings Distribution

🎬 Director-wise Analysis

🎛️ Interactive Filters (Country, Director & Type)

---

## 📈 Key Insights

✔️ Movies make up the majority of Netflix's content.

✔️ Drama is one of the most popular genres.

✔️ Netflix offers content from many countries.

✔️ Content ratings vary across different types of shows.
